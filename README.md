# 工務處工作準則｜桌機／筆電版 GitHub Pages

此版本為獨立的寬螢幕介面，建議使用 1280px 以上的筆電或桌上型電腦瀏覽。

## 上傳方式

1. 將 `index.html`、`style.css`、`script.js` 上傳到同一個 GitHub Repository 的根目錄。
2. 在 Repository 開啟 `Settings` → `Pages`。
3. `Source` 選擇 `Deploy from a branch`。
4. Branch 選擇 `main`，資料夾選擇 `/ (root)`，再按 `Save`。

網站內容依照最新版 Google 試算表「工務處工作準則」製作，包含 40 個原始超連結。
